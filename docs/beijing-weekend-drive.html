周六详细行程 · 🌧️ 延庆环线 龙庆峡 + 世园 + 野鸭湖 + 官厅水库
周六 🌧️ 西小口 → 龙庆峡（坐船）→ 世园 → 野鸭湖 → 官厅 → 京藏 → 回家 🛣️ ~340 km · 🚗 5h 40min
7:30 出发
🚗 西小口 → 京礼高速 → 龙庆峡 85km · 1h30min
京礼高速北上，经昌平、延庆到龙庆峡。雨天高速车少，练习雨中控速和跟车距离。
9:00 — 11:00
⛰️🚢 龙庆峡 · 进景区 + 坐船游湖（2h）
买票进景区，坐游船穿越峡谷段（约 5 km 水路），两岸悬崖从水面仰望更震撼。船程 40–60 min。雨天峡谷烟雾缭绕，比晴天更有意境。
11:00 — 11:30
🍽️ 车上快速午餐 + 龙庆峡 → 世园公园
车上吃提前买好的面包/饭团。沿延庆城区公路到世园公园 15 min。15km · 20min
11:30 — 12:00
🌿 世园公园 · 开车绕园一圈 8km · 30min
园区内道路宽敞，雨天几乎没游客。妫水河穿园而过，开车慢行看两侧展馆和湿地。不下车，纯开车绕一圈。
12:00 — 12:20
🚗 世园公园 → 野鸭湖 12km · 20min
从世园出来沿康张路往北，20 分钟到野鸭湖。路上经过延庆湿地片区。
12:20 — 12:40
🦆 野鸭湖 · 湿地公路穿越 6km · 20min
沿野鸭湖外围公路开，透过车窗看大片芦苇荡和湖面。不进景区，开车路过。
12:40 — 13:00
🚗 野鸭湖 → 官厅水库东岸 15km · 20min
从野鸭湖沿康张路南行到官厅水库东岸。水面比密云水库还大。
13:00 — 14:00
💧 官厅水库 · G110 国道沿湖驾驶 40km · 1h
周六最爽的一段。G110 国道贴着官厅水库南岸走，双向两车道，路面好、车少，左手边就是广阔湖面。雨天湖面雾气蒸腾，像开在海边。
14:00 — 15:30
🚗 官厅 → 京藏高速 → 昌平 80km · 1h30min
官厅附近上京藏高速（G6），和去程的京礼高速不重复。经八达岭、居庸关，隧道群密集——雨天穿隧道是很好的灯光切换练习。
15:30 — 15:50
☕ 昌平休息 · 加油
下车活动一下，加满油，买杯咖啡。
15:50 — 17:20
🚗 昌平 → 京藏/京新高速 → 西小口 65km · 1h30min
京藏高速或京新高速南下回五环。雨天最后一程高速，开稳到家。
17:30
🏠 到家 · 周六结束
今天开了 ~340 km / 5h 40min，龙庆峡坐船 + 延庆环线四景。晚上好好休息，明天继续。

🌧️ 周六雨天驾驶 checklist
① 出发前确认雨刮正常，胎压正常
② 全程开近光灯 + 雾灯（不开双闪，除非临时停车）
③ 高速跟车距离拉大到平时的 2 倍（100km/h → 保持 100m 以上）
④ 京藏高速隧道群：入隧道前减速、开灯，出隧道注意光线变化
⑤ G110 国道沿湖段：路肩可能有积水，尽量走车道中间
⑥ 车内除雾：开 AC + 外循环，出风口吹前挡

周日详细行程 · ☀️ 三湖+两谷+顺平路 雁栖湖 → 密云水库 → 金海湖 → 大峡谷 → 顺平路 80km 回
周日 ☀️ 西小口 → 雁栖湖 → 密云水库南线 → 金海湖 → 大峡谷 → 顺平路 → 回家还车 🛣️ ~340 km · 🚗 7h 30min
6:30 出发
🚗 西小口 → 京承高速 → 雁栖湖 50km · 1h10min
早起出发，京承高速北上。早晨空气好，能见度佳。
7:40 — 8:10
🚗🏞️ 雁栖湖环湖公路 15km · 30min
P5 → 环湖东路 → "日出东方"酒店 → 环湖西路 → P5。纯开车看景，不下车。
8:10 — 8:55
🚗 雁栖湖 → 京承高速北上 → 密云水库 40km · 45min
再次经过密云城区，继续北上到水库大坝。
8:55 — 9:15
💧 密云水库大坝 · 快速打卡
大坝上看水库全景，20 min。不久留，后面重头戏多。
9:15 — 10:45
🚗💧 密云水库南线环线（核心驾驶段）60km · 1h30min
密关路 → 太师屯 → 新城子方向，沿水库南岸绕行 60 km。柏油双向两车道，弯道多、上下坡交替，新手练车绝佳路段。
10:45 — 11:00
☕ 太师屯 · 路边休息
连续驾驶 1.5h 该歇了。买瓶水、活动一下。
11:00 — 11:40
🚗 密云 → 密三路 → 金海湖 35km · 40min
密三路南下到平谷金海湖。县道车少，白天晴天没问题。
11:40 — 12:20
🚗🌊 金海湖环湖 10km · 20min
"京郊小瑞士"，开车绕湖一圈。湖面宽广，多个观景平台。
12:20 — 13:10
🍽️ 金海湖午餐
湖边农家院，水库鱼招牌。
13:10 — 13:30
🚗🏔️ 金海湖 → 黄松峪水库 8km · 15min
路边就能看到水库和残长城遗址。停车 5 min 拍照就走。
13:30 — 13:55
🚗⛰️ 黄松峪 → 京东大峡谷入口 12km · 20min
峡谷公路，两侧山崖压迫感很强。开到停车场看龙门湖和一线天，不进景区，门口感受山势就走。
13:55 — 14:20
🚗 大峡谷 → 平谷城区 15km · 25min
从峡谷出来沿路到平谷城区。接下来是今天的压轴驾驶段。
14:20 — 16:20
🚗🛣️ 平谷 → 顺平路 S323 → 顺义 → 西小口 80km · 2h
周日压轴！不走高速，走顺平路（S323 省道）。80 km 双向两车道省道，穿十几个村镇、无数红绿灯和路口——这才是新手最需要练的综合路况。比高速值钱 10 倍。
16:30
🏠 到家 · 加油 · 还车
到家后加满油、拍油表和里程表、检查车况。17:00 前到还车点，20:00 前还车绰绰有余。今天 340 km / 7h 30min，两天总计 680 km / 13h。

⚠️ 关键提醒

  • 确认租车合同：不限里程、允许过夜开回家。两天 ~680 km，确认不超限。
  • 停车停小区或正规停车场，别停路边。
  • 周日晚上 8 点还车。建议周日 17:00 前到家，留出加油+检查时间。
  • 还车前加满油，保留加油小票，拍油表和总里程。
  • 新手别走：范崎路、延琉路老路、百里画廊滦赤路、红井路。
  • 山路只在白天开，绝不夜间进山。
  • 周六有雨：全程走高速避开山路，开近光灯+雾灯，跟车距离翻倍。
  • 密三路（密云→金海湖 35km）：晴天没问题，弯道慢一点即可。
