# 项目周报存储目录

本目录用于存储每周的项目周报数据。

## 目录结构

```
weekly-reports/
├── README.md                    # 本说明文件
├── 2026-W38.json               # 按周存储的周报数据
├── 2026-W39.json
└── ...
```

## 文件命名规范

- 格式：`YYYY-WXX.json`
- 示例：`2026-W38.json`（2026年第38周）

## 数据结构

每个JSON文件包含以下结构：

```json
{
  "week": "2026-W38",
  "projects": [
    {
      "id": 1234567890,
      "name": "项目名称",
      "tasks": [
        {
          "id": 1234567890,
          "task": "事项内容",
          "progress": "80%",
          "owner": "负责人",
          "estimatedCompletion": "2026-09-25"
        }
      ],
      "risks": [],
      "coordination": []
    }
  ]
}
```

## 使用说明

1. 每周五通过项目管理HTML工具填写周报
2. 点击"导出JSON"按钮下载周报数据
3. 将下载的JSON文件上传到本目录
4. 文件命名遵循 `YYYY-WXX.json` 格式

## 分类说明

每个项目包含三类事项：

- **tasks**：项目事项 - 项目的主要工作内容和进度
- **risks**：项目风险 - 可能影响项目的风险点
- **coordination**：需要拉通的事项 - 需要跨部门或跨团队协调的事项
