# Cherry Studio 与飞书、企业微信打通项目

## 项目概述

将飞书、企业微信等多平台消息整合到 Cherry Studio AI 助手中，实现一站式消息管理和智能总结。

## 项目目标

1. **消息整合**：在一个界面中处理所有平台的消息
2. **智能总结**：AI 自动总结和分类消息内容
3. **待办管理**：跨平台待办事项统一管理
4. **日程管理**：跨平台日程创建和查询
5. **会议管理**：跨平台会议创建和管理

## 技术架构

```
Cherry Studio (AI 中枢)
    ↓ MCP 协议
─────────────────────────────────────┐
│  飞书 lark-cli    │  企业微信 wecom-cli  │
│  (已安装 v1.0.92)  │  (已安装 v1.2.0)    │
└─────────────────────────────────────┘
    ↓ API 调用
┌─────────────────────────────────────┐
│  飞书开放平台     │  企业微信开放平台    │
└─────────────────────────────────────
    ↓
消息 / 任务 / 联系人 / 邮件 / 日程 / 会议 / 文档
```
