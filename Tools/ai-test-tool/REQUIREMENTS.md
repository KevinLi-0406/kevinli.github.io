# AI API 测试工具 - 需求文档

## 项目概述

AI API 测试工具是一个用于测试和对比多个 AI 模型 API 的 Web 应用。支持同时向多个模型发送请求，对比响应速度和质量，并提供统计分析功能。

**访问地址**: https://kevinli-0406.github.io/kevinli.github.io/Tools/ai-test-tool/index.html

---

## 功能需求列表

### 第一阶段：基础功能（2026-09-04 13:50 - 14:49）

#### 1. 基础对话功能
- **需求描述**: 支持输入消息并发送到选中的 AI 模型
- **实现状态**: ✅ 已完成
- **详细说明**: 
  - 用户输入消息后按 Enter 或点击发送按钮
  - 消息同时发送到所有选中的模型
  - 支持 Shift+Enter 换行

#### 2. 多模型并排对比布局
- **需求描述**: 回复的展示需要分块展示，能一下子看出来各个模型回复的内容，而不是需要一直向下滚动
- **实现状态**: ✅ 已完成
- **详细说明**:
  - 每轮对话包裹在独立的容器中
  - 用户消息居中全宽显示
  - 下方模型回复用 CSS Grid 并排展示
  - 每个模型有独立的列（header + body）
  - 模型列头部实时显示响应速度（⚡ 标签）
  - 错误时列边框变红，便于快速识别失败模型

#### 3. 模型标签系统
- **需求描述**: 模型能不能打标签？比如嵌入/重排/推理/视觉等标签，以及推理强度的标签，这些标签如果能打，那我希望能够根据标签来分类和筛选
- **实现状态**: ✅ 已完成
- **详细说明**:
  - 根据模型名称自动匹配标签（对话/推理/视觉/嵌入/重排/代码/图像/语音合成/语音识别）
  - 推理强度标签：轻量/标准/重度推理，自动识别 o1/deepseek-r1/qwq 等推理模型
  - 标签筛选栏：按模型类型和推理强度分组筛选
  - 标签筛选逻辑：从 AND 改为 OR 逻辑（选"推理"会显示所有推理模型）

#### 4. 模型搜索功能
- **需求描述**: 支持按模型名称模糊搜索
- **实现状态**: ✅ 已完成
- **详细说明**:
  - 新增搜索框支持按模型名称模糊搜索
  - 实时过滤，带清除按钮
  - 搜索与标签筛选可联动使用

#### 5. API Key 安全改进
- **需求描述**: key不要写在网站里，每次等用户输入就好了
- **实现状态**: ✅ 已完成
- **详细说明**:
  - API Key 不再保存到 localStorage
  - 每次手动输入，避免泄露风险
