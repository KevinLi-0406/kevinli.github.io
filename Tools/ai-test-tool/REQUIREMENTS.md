# AI API 测试工具 - 需求文档

## 项目概述

AI API 测试工具是一个用于测试和对比多个 AI 模型 API 的 Web 应用。支持同时向多个模型发送请求，对比响应速度和质量，并提供统计分析功能。

**访问地址**: https://kevinli-0406.github.io/kevinli.github.io/Tools/ai-test-tool/index.html

---

### 需求内容

本工具提供以下核心功能：

1. **多模型批量测试**：支持同时向多个 AI 模型发送相同的请求，一次性获取所有模型的响应结果
2. **并排对比展示**：各模型的回复内容以 Grid 布局并排展示，可直观对比不同模型的输出质量
3. **响应速度统计**：实时记录每个模型的响应耗时，提供排序、进度条可视化等统计分析
4. **模型分类筛选**：自动识别模型类型（对话/推理/视觉/嵌入/重排/代码/图像/语音等）和供应商，支持多维度筛选
5. **连通性测试**：一键批量测试模型可用性，自动区分可用/不可用模型
6. **AI 分析结果**：调用 AI 模型对当前会话的所有测试结果进行综合评价
7. **历史记录追溯**：保存对话历史和 AI 分析历史，支持回溯查看和重新分析

---

### 需求目标

| 目标 | 说明 |
|------|------|
| **效率提升** | 将原本需要逐个测试的模型对比工作，简化为一次操作完成全部模型的测试和对比 |
| **可视化对比** | 通过并排布局、速度排名、进度条等方式，让多模型差异一目了然 |
| **快速筛选** | 通过标签、供应商、类型等多维度筛选，快速定位目标模型 |
| **质量评估** | 通过 AI 分析功能，自动评估各模型的响应速度、成功率和回复质量 |
| **零部署使用** | 纯前端实现，通过 GitHub Pages 部署，无需后端服务，打开即用 |

---

### 需求价值

- **对开发者**：快速评估不同 AI 模型在同一任务上的表现差异，辅助技术选型决策
- **对产品经理**：直观对比各模型的响应速度和质量，为产品接入 AI 能力提供数据支撑
- **对运维人员**：批量检测模型连通性，快速发现不可用的 API 端点
- **对团队**：统一的测试工具标准化了模型评估流程，减少重复劳动

### 待改进事项

| 优先级 | 改进项 | 说明 |
|--------|--------|------|
| 🔴 高 | 数据持久化 | 当前数据仅在内存中，刷新页面即丢失。需要支持 localStorage 或导出/导入功能 |
| 🔴 高 | 流式响应支持 | 当前等待完整响应后才展示，应支持 SSE 流式输出，提升用户体验 |
| 🟡 中 | 自定义 Prompt 模板 | 支持预设常用测试 Prompt 模板，一键快速测试 |
| 🟡 中 | 测试结果导出 | 支持将测试结果导出为 CSV/JSON 格式，便于离线分析 |
| 🟡 中 | 多轮对话支持 | 当前仅支持单轮问答，应支持上下文连续对话 |
| 🟡 中 | 移动端适配 | 当前右侧面板在小屏幕隐藏，需要更好的移动端交互设计 |
| 🟢 低 | 暗色/亮色主题切换 | 当前仅支持暗色主题，可增加亮色主题选项 |
| 🟢 低 | 模型收藏功能 | 支持收藏常用模型，快速选择 |
| 🟢 低 | Token 消耗统计 | 统计每次请求的 Token 消耗量，辅助成本评估 |
| 🟢 低 | 并发数控制 | 支持设置并发请求数，避免触发 API 限流 |
